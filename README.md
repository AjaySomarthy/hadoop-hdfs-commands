# Hadoop HDFS Commands

A collection of **Hadoop HDFS commands and practice examples** covering fundamental and commonly used Hadoop Distributed File System (HDFS) operations.

This repository is focused specifically on **Hadoop HDFS commands** used for file management, directory operations, data movement, and file system administration.

## 📚 Topics Covered

### HDFS File and Directory Operations

- Creating Directories (`mkdir`)
- Listing Files and Directories (`ls`)
- Viewing File Contents (`cat`, `text`, `tail`)
- Uploading Files to HDFS (`put`, `copyFromLocal`)
- Downloading Files from HDFS (`get`, `copyToLocal`)
- Copying Files (`cp`)
- Moving and Renaming Files (`mv`)
- Deleting Files and Directories (`rm`, `rmdir`)
- Checking File and Directory Sizes (`du`, `dus`)
- Checking HDFS Storage Usage (`df`)
- Counting Files and Directories (`count`)

### HDFS File Management

- Changing File Permissions (`chmod`)
- Changing File Ownership (`chown`)
- Changing Group Ownership (`chgrp`)
- Checking File Information (`stat`)
- Testing File and Directory Existence (`test`)
- Merging HDFS Files into a Local File (`getmerge`)
- Updating File Timestamps (`touchz`, `touch`)
- Appending Data to Files (`appendToFile`)

### HDFS Administration and Monitoring

- Checking HDFS Cluster Health (`dfsadmin -report`)
- Checking File System Health (`fsck`)
- Checking HDFS Safemode Status (`safemode`)
- Managing HDFS Replication (`setrep`)
- Checking HDFS Trash (`expunge`)
- Restoring Deleted Files from Trash
- Starting and Stopping NameNode and DataNode Services

## 🎯 Purpose

This repository is created for:

- Learning and practicing Hadoop HDFS commands
- Understanding HDFS file and directory operations
- Gaining hands-on experience with Hadoop Distributed File System
- Practicing file uploads, downloads, copying, moving, and deletion operations
- Understanding HDFS permissions, storage usage, and file management
- Improving Hadoop troubleshooting and monitoring skills
- Preparing for Hadoop and Big Data-related interviews
