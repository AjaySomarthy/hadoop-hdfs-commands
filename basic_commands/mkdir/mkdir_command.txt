Creating a directory in HDFS :

-- Creating a single directory
hdfs dfs -mkdir /demo
hadoop fs -mkdir /demo


-- This will throw an error as "one" folder is not existed
hdfs dfs -mkdir /demo/one/students
hadoop fs -mkdir /demo/one/students


-- Creating multiple directories
hdfs dfs -mkdir /hello /hello/one /hello/two /hello/three
hadoop fs -mkdir /hello /hello/one /hello/two /hello/three
