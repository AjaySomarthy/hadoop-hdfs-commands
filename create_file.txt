Creating a file in HDFS directory :

-- To create a empty new file in a any directory in one instance
hdfs dfs -touchz /learning/school_students.txt

-- To create multiple empty new files in different directories in one instance
hdfs dfs -touchz /hello/one/file1.txt /hello/two/file2.txt /hello/three/file3.txt


-- To create a new file with content in it, we use
hdfs dfs -put - /learning/school_teachers.txt

Enter your content.
After, Ctrl+D and Enter for saving and exit
