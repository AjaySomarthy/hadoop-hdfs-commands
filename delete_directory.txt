Deleting a directory in HDFS :

-- To delete a single directory along with its subdirectories and files, we use
hdfs dfs -rm -r /learning

-- To delete a directory forcefully by avoiding any error messages such as path or directory is not existed, then use -f flag
hdfs dfs -rm -r -f /learning/demo
------------------------------------------------------------------------------------------------------------------------------------------------------------------------
-- Deleting multiple directories in a single shot :

-- To delete multiple required directories, we use :
hdfs dfs -rm -r /hello/one /hello/two /hello/three

-- To delete all the subdirectories and files in a directory, we use
hdfs dfs -rm -r /hello/*
------------------------------------------------------------------------------------------------------------------------------------------------------------------------
-- Removing an empty directory
hdfs dfs -rmdir /demo1

-- If you try -rmdir on non-empty files, you will get an error
hdfs dfs -rmdir /demo2

error message :
rmdir: `/demo1': Directory is not empty

Note : For any directory using "-rm -r" is a best choice
