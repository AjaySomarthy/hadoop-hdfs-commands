First, Open Windows PowerShell

You will be in Windows PowerShell
You can see like below :
PS C:\Users\ajayk>

Now, you have to open Ubuntu from PowerShell
So, execute the below in PowerShell :
wsl -d Ubuntu

Now, you can see like below :
ajaykumar@LAPTOP-B******T:/mnt/c/Users/ajayk$

Here, you are not in home directory
So, you should go to home directory
Execute the below :	
cd ~

Now, you can see like below :
ajaykumar@LAPTOP-B******T:~$

Now, you are in home directory
Note : You need to start Hadoop NameNode and DataNode services inside Ubuntu only, not in Windows PowerShell

Now, start Hadoop services : NameNode & DataNode
// Starting NameNode
hdfs --daemon start namenode

// Starting DataNode
hdfs --daemon start datanode

Now, verify the Hadoop services
Execute the below :
jps

you can see like below :
512 NameNode
835 Jps
787 DataNode

// Note : Process IDs will be different for you

Now, you are in hadoop area
You can start with your hadoop HDFS commands


NameNode Web Interface :

http://localhost:9870
